**CodSoft Java Development Internship**



**About This Project**



This repository contains Java programs developed as part of my CodSoft Java Development Internship.



**Tasks Completed**



Task 1: Number Game



A number guessing game that generates a random number between 1 and 100. The user guesses the number within a limited number of attempts.



Task 2: ATM Interface



A console-based ATM application that allows users to check their balance, deposit money, and withdraw money.



Task 3: Quiz Application



A multiple-choice quiz application that checks answers and calculates the user's score.



Task 4: Student Course Registration System



A program that displays courses, allows students to register for courses, and supports course removal.
